# Missing You：使用者產品指南（繁體中文）

Missing You 是一個平靜、以隱私為優先的回憶書寫空間，讓你為想念的人留下文字。

你的完整內容會保存在鏈下。  
鏈上只錨定密碼學證明，方便日後驗證真實性。

---

## 你可以做什麼

- 在乾淨、溫和的編輯器中書寫回憶
- 將內容保持私人，或選擇公開分享
- 把證明錨定到區塊鏈（不暴露全文）
- 驗證公開回憶是否被修改
- 使用英文或繁體中文介面

---

## 快速開始（1 分鐘）

1. 使用 Email 登入
2. 寫下一段回憶
3. 儲存為草稿
4. 視需要把證明錨定上鏈
5. 視需要建立公開分享連結

---

## 視覺化使用流程

```text
使用 Email 登入
  -> 書寫回憶
  -> 完整內容儲存在鏈下
  -> [選擇性] 將證明錨定到鏈上
     -> 產生標準化承載與雜湊
     -> 提交到 MemoryRegistry
     -> 將交易後設資料保存在鏈下
  -> 設定可見性
     -> 私人：僅擁有者可見
     -> 可分享：生成公開回憶頁
  -> 取得連結者可查看並驗證證明資訊
```

---

## 一段有畫面的使用旅程

想像小美想保存一段關於外公的回憶：

1. 她先用 Email 登入。
2. 她寫下一段真誠的文字並儲存。
3. 這段內容只會保存在資料庫，不會直接上鏈。
4. 她選擇把證明錨定到鏈上。
5. 系統產生的是穩定的數位指紋（hash），不是文章全文。
6. 她拿到交易紀錄，能證明這段回憶在某個時間點已存在。
7. 幾週後，她決定開啟分享，把公開連結傳給家人。
8. 家人可以查看公開頁並驗證真實性，但看不到她未分享的私人內容。

結果：情感內容被妥善保存，信任也有可驗證依據。

## 隱私與信任（簡單版）

- **預設私人**：完整內容保存在鏈下。
- **上鏈僅證明**：上鏈的是記憶鍵、雜湊與必要後設資料，不是全文。
- **可自行控制分享**：擁有者可調整可見性。
- **內建驗證能力**：公開頁可驗證是否與錨定證明一致。

---

## 主要頁面

- **書寫頁**：建立回憶（可展開「你的字會去哪裡」信任說明）
- **回憶列表**：依紀念對象分組／篩選；若尚無任何一則，會出現可略過的歡迎與信任導讀
- **回憶詳情（擁有者）**：錨定流程逐步說明、錯誤時可再試；管理可見性
- **公開回憶頁**：誰能看見的提示、內文，以及白話的「驗證代表什麼」
- **隱私與安全**（`/privacy-security`）：給讀者與營運參考的隱私、速率限制與安全摘要
- **設定頁**：帳號與錢包綁定

## 常見問題

### 我的完整日記會上鏈嗎？
不會。完整內容保存在鏈下資料庫。

### 鏈上到底會存什麼？
證明後設資料（記憶鍵、內容雜湊、擁有者/時間/分享狀態）。

### 我可以再改回私人嗎？
可以。擁有者可切換可見性。

### 其他人可以驗證公開回憶嗎？
可以。公開頁會提供必要證明資訊供驗證。

## 產品承諾

Missing You 想提供的是：

- 溫柔且專注的書寫體驗
- 實用而不打擾的隱私保護
- 可長期驗證的真實性證明
